# Nokcandu 0.13.2

- **What's New shows every version you missed.** If you update across several versions, the notes for each one appear, newest first (the ten most recent at most, with a link to the rest). Before, only the newest version's notes were shown.
- **The sort and filter button is only on the Games tab.** It applies to the games list, but used to sit over Controls and Streams as well.
- Subheadings in the What's New window are drawn as headings instead of showing "###".
