# Nokcandu 0.15.0

## Streams: lower latency

- **New: Metal renderer** (Picture → Renderer → "Metal (CAMetalLayer)"), with a **V-sync** switch. With V-sync off, a frame is on screen about 5–6 ms after it's decoded; this Mac's total measured 7–8 ms on a MacBook Air. If Metal can't start, the stream falls back to the display layer (AVSampleBufferDisplayLayer) by itself. Colours follow the display, wide-gamut (P3) displays included, and HDR streams work with Metal too. Both settings apply immediately during a stream.
- **V-sync on** now waits for the display's refresh on its own thread instead of adding frames of delay: about 40 ms instead of 70 on a 60 Hz screen. V-sync off is still recommended for the lowest latency, and Settings says so when V-sync is on.
- **Recommended settings**: new stream profiles start with the settings measured with the lowest latency (2560×1600 at the display's refresh rate, automatic bitrate, HEVC, Metal with V-sync off, lowest-latency pacing, full-range colour, full screen). A profile that differs shows **Use Recommended Settings** to put them back. Display, sound, controllers and the app aren't changed.
- Streaming-core fixes for lost packets: a frame missing a few packets is recovered more often instead of waiting for a new key frame.

## Streams: statistics

- **Decode → screen** time is shown (measured with Metal, estimated with the display layer), and **this Mac's total** is coloured: green under 12 ms, yellow under 20, orange above.
- **Whole-stream averages** and the time 99% of frames stayed under, beside the last second's figures. The first 3 seconds of a stream (while things settle) are left out.
- **New statistics mode: FPS and latency**, just the frame rate and this Mac's total, like `90/7.8`. The modes are now Off, FPS and latency, Standard and Detailed. ⌃⌥⇧S cycles through them during a stream.

## Streams: picture and screen

- **"This Mac's display" asks for the screen's own pixels** (2560×1608 below the notch on a 13-inch MacBook Air), whatever its "looks like" setting. Before, a scaled setting asked the host for an oversized picture.
- **Full-screen sizes on a MacBook with a notch**: the Resolution menu lists the whole screen's sizes (for example 2560×1664 and 1920×1248). Pick one with Full screen on and the stream fills the screen beside the camera too, also from the green button. This uses a few milliseconds more latency than full screen below the notch.
- **Fixed a washed-out picture** when the host resumed an app that was started with limited-range colour: the colour range now comes from the stream itself.
- **Settings the host keeps from the start**: when you change one (like the resolution) and the app is still running on the host, Nokcandu offers to restart the app so the change takes effect.
- **Fixed the custom resolution fields** turning the number into 320 or 200 while you backspaced. The size applies when you press Return or leave the field.

## Streams: input and controls

- **Hold Esc for 5 seconds** to free a captured pointer; a bar appears after the first second. The start-of-stream hint with the ways out now shows for 15 seconds.
- **⌃⌥⇧K** sends the Mac's shortcuts to the host or keeps them on the Mac, for that stream.
- Extended keys (right Control and Alt, the arrows, Insert, Delete, Home, End, Page Up, Page Down, keypad /, the Windows and Menu keys) reach the host as extended keys, so games that tell them apart from the keypad keys see the right ones.
- **DualSense adaptive triggers** from the host (resistance, weapon and vibration effects) are applied to the controller.
- Sunshine hosts see this Mac as its own client.

## Wake Up

- **The Wake Up button shows what happened**: sending the magic packet, the host being awake, or, if it hasn't answered after 2 minutes, what to check.
