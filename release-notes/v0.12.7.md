# Nokcandu 0.12.7

## Crashes explained

- When a Windows game crashes, Nokcandu now keeps Wine's crash report and explains it on the game's page in plain words: a mod missing a mod it needs, a crash in the graphics, sound or video playback, a program reading data that isn't there, and so on. **Show Report** has the full report with **Copy Report** for sharing it. Wine's own crash dialog no longer appears (a debugger you set up yourself is left alone).
- **Mods that need other mods** (Battlefield 1942, Battlefield Vietnam and their mods): a mod whose `init.con` builds on a mod that isn't installed — for example FHSW without Forgotten Hope — is pointed out on the game's page, when Play starts it, and in Diagnostics, instead of the game crashing while loading.

## Fixes

- **Wine 11 games run as their own app again**: their name and icon in the Dock and the games category macOS needs for Game Mode. They had been running under Wine's own identity.
- **Battle.net: Play while Battle.net is already open** starts the game again. Game launchers made by older versions of Nokcandu are now brought up to date (they missed the Wine 11 settings, so Battle.net received the request but didn't act on it). Launchers you edited by hand are left as they are.
- A game macOS holds while it checks changed files (which can take minutes when its online check is slow) is shown as still starting rather than as failed.
- **Eject** names the app that's still using a drive or games volume.

## Known issues

- The microphone-Off permission prompt and the Battlefield 2 fullscreen Spaces input issue remain open.
