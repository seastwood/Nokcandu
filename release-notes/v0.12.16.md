# Nokcandu 0.12.16

## Controller profiles — original Steam Controller

- **A trackpad can be four directions.** W A S D on the left pad, arrows on the right, or anything you set for each way; diagonals hold both.
- **Each pad has an edge.** Set its size and give it a key or button: it is held while your thumb is at the rim, together with whatever the pad is doing — Shift to sprint when you push W A S D all the way, for example.
- **The picture shows your pad settings:** the pad's angle, the edge ring at its size (it lights up as you touch it), and what each direction does.
- The Steam Controller picture is closer to the real thing: bigger trackpads and the three centre buttons higher up.
- **A layer can have its own pad settings** — a slower pad while aiming, or directions in a menu layer.
- **A ready-made Steam Controller profile** under New Controller Profile: right pad aims as a trackball, left pad walks with W A S D and sprints at its edge, triggers click.
- Routing choices have plain names, and Smoothing replaces the old Small movement steadiness slider (it still shows if a profile uses it).

## Library

- **Drag games onto a category's title** to file them, and drag a category's title onto another to reorder.
- The Refresh button is gone: the library updates itself when you come back to Nokcandu (File → Refresh Library is still there).

## Lighter while you play

- The controller editor's live test stops while Nokcandu is behind another app, and redraws far less while you use it.
- On-screen notes (gyro calibration, layer changes) cost much less to show.
- macOS no longer naps Nokcandu while a profile is mapping a controller, so input timing stays even behind a game.
- Leftover files from games that were force-quit are cleaned up at start.

## Online play

- **Your game's own store app keeps its full priority.** While a game is in front, Nokcandu puts store apps in the background — which on a Mac also slows their network and disk. That was applied to Steam and Battle.net even when the game you were playing belongs to them and talks to them all through an online match. Now only the store apps you aren't playing through step back.
- **Wine's server runs at the highest priority**, so the game's network and file requests aren't left waiting on a slow core when the processor is busy.
