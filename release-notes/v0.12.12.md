# Nokcandu 0.12.12

## Controller profiles

- **Mac games can have a controller profile too,** on their page. Best for Mac games without controller support (or with it turned off), since the game also sees the controller itself.
- **Activate any profile, anywhere.** Right-click a profile → Activate Everywhere, or the menu bar's Use a Profile Everywhere: that profile applies in every app and game until you deactivate it — for streaming, or trying a profile without a game.
- **Right-click a profile or keyboard layout** in the Profiles tab: activate, use on the Mac, set as default, edit, rename, duplicate or delete.
- **The active profile is marked** in the sidebar with a green dot and where it's applying (everywhere, the game in front, an app, or the Mac).
- **Duplicate** a profile from its page to tweak a copy for another game.
- **Button labels:** Switch Pro Controllers are recognised as controllers (they describe themselves as joysticks), the editor picks your controller's labels by itself, and remembers the labels you choose for each controller.
- **The Profiles tab's New buttons line up.**
