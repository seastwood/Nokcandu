# Nokcandu 0.12.4

## Profiles and compatibility fixes

- Fixed profiles applying their settings without installing the compatibility components they listed. Applying a profile now installs supported built-in components, reports anything unavailable or incomplete, and keeps Undo available.
- Applicable game-local fixes now work with Steam, Battle.net, EA and Ubisoft games. Shader libraries, DirectX extras and renderer choices stay attached to the selected game rather than changing the shared launcher or other games.
- Added **Program for fixes**, so you can choose the game executable separately from the program its launcher starts.
- Fixed profile validation differences between the app and community catalog. New shared-launcher profiles use schema 3, which older apps safely skip; existing profiles remain supported.
- Improved DirectX 8 eligibility for games started through a different-architecture launcher.
- Added a verified Battlefield 1942 software-sound fix for the menu crash associated with hardware audio. Profiles can include it.
- Changing a game's program no longer requires finding and manually undoing unrelated display settings. Added an icon editor that can take an icon from another executable without changing the launch program.

## Settings and reliability

- Saved changes that require a closed game now apply automatically when its Windows environment becomes idle. Pending controls show which settings are waiting; shared clients must also close where required.
- Removed the unexplained Preview badge from the installation window.
- Fixed a runner-only crash in the pending-settings monitor and strengthened real Wine regression checks.
- Routine engine-version checks no longer require a Mac build runner. Mac builds still run when a new engine needs testing.

## Notes and known issues

- Some components still have specific requirements. Shared-client IPX needs a private Windows environment; the borderless launch wrapper currently supports direct EA launches. Video playback and PhysX components affect the whole shared Windows environment, as labelled.
- Existing generated launchers and owned helper files migrate safely. Manually edited launchers, changed component files, game content, saves and explicit settings are preserved. Use a component's **Undo** to remove it.
- The microphone-Off permission-prompt issue disclosed in 0.12.3 remains unresolved: some Wine games can still ask macOS for microphone permission while the switch is Off. This release does not claim to fix that dialog. Choose **Don't Allow** when input is not wanted.
- Battlefield 2 can still lose input after switching macOS Spaces with the resizable virtual screen in fullscreen. That investigation remains deferred; disabling the resizable virtual screen is the reported workaround.
