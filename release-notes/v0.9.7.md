**Smoother mouse, fewer interruptions.**

### Mouse
- **Raw mouse capture** (renamed from "Raw mouse for aiming") is on by default and its on/off and speed now apply **while you play**.
- Only takes over when a game really captures the mouse (re-centres or confines it) — games that draw their own cursor (Diablo's inventory) keep the normal pointer.
- Fixed: Raw mouse fell back to a slower path (macOS refused mouse access) — games keep the permissions of the app that started them again.
- Movement is handed to the game once per frame, so every frame turns by exactly one frame's worth.

### Full-screen play
- **Hot corners are paused** while a game is full screen and in front, and come back as soon as you switch away (restored even if a game crashes).
- **Low-delay vsync** for Apple Metal and DXMT (frames wait for the refresh, at most one at a time), **DXMT frame limit**, and **Low-latency mode** for Classic/Modern 3D.

### Reliability
- Pressing Play closes a copy of the game left over from an earlier run with no window (Battle.net wouldn't start D2R again).
- Diablo II Resurrected and other Battle.net games now get Nokcandu's helper library (names, Game Mode, raw mouse).
- Optional **Smoother Steam windows (GPU drawing)** on Steam's page.
- Low-latency aiming is on by default for new Valve games.
