# Nokcandu 0.12.10

## Easier to use

- **Recommended setup at the top of the page.** Games Nokcandu has a known setup for (Overwatch 2, Battlefield 1942) show one card above everything else, with a single button, until it's applied or you choose Not Now.
- **When Play doesn't start the game, Nokcandu says so.** If Battle.net, Steam or another store opened but the game hasn't appeared 90 seconds after it was asked to start it, the game's page explains what's probably waiting (an update, a sign-in or the store's own Play button) with Try Again and a button to open the store.
- **New store games are announced.** When a game you installed in a store is added to your library, the message names it, Recent Activity has a Show button for it, and a Mac notification appears if Nokcandu is in the background.
- **Crash history.** Each Windows environment keeps its last 12 crash reports instead of only the newest, and a game's crash notice says when it has crashed several times in a week (and whether the same way each time).
- **Low-memory warning while you play.** A game using most of the Mac's memory gets a message (and a Mac notification in the background) during the session, not only on its page afterwards.
- **What's New** appears once after an update, and any time from Help → What's New in Nokcandu.
- **Reset to Recommended** (game page → Wine & Fixes, next to Repair): takes a restore point, undoes every fix, and applies the recommended setup again, including suggestions you chose Not Now for.
- **VoiceOver**: icon-only buttons (activity, sort, filter, rename, delete, refresh, keep engine) have names, notices read their title as a heading, and At a Glance rows say where they lead.
- Settings → General: turn Mac notifications off if you'd rather not have them.

## Also

- Low-memory DXMT installs the newest verified Overwatch build of it.
- Release checksum files name the file only, so `shasum -c` works next to the download.
- Overwatch Setup says when it's done instead of showing a disabled button.
