## New in 0.11.0

- **Play in a resizable window.** Turn it on for any Windows game (Steam, Battle.net, EA, your own): the game runs on a virtual screen in a normal Mac window you can move, resize, minimize and make full screen, while your Mac's display stays as it is. Pick a resolution or Automatic (follows the game); change it while the game runs. Each game keeps its own choice, even games sharing a launcher, and profiles include it. Works best with the game set to full screen in its own settings.
  - Control-Command-C frees the mouse or gives it back (a note over the game reminds you), Control-Command-F switches full screen, Shift-Command-Esc always frees the mouse.
  - Launcher windows (Steam, Battle.net) stay separate Mac windows.
- **Local network games with the Mac's Bonjour.** Windows games that use Bonjour — StarCraft's Local Area Network, for one — talk to macOS's own Bonjour. Games that insist on their own Windows Bonjour service get a stand-in that keeps them happy.
- **Sound follows your Mac.** Plug in headphones or pick another output while a game runs and its sound moves along (microphones too).
- **Play always starts.** If macOS refuses to open a game's app, Nokcandu clears the problem and tries again, then starts the game directly.
- **Nokcandu knows what's running**, including games started by Battle.net, Steam or the EA app, and after Nokcandu restarts. Stop also reaches every program in a game's environment.
- **Tidier settings.** Every setting is one row with its control on the right; explanations moved into (i) buttons.
- **Credits.** Settings → Credits lists the open-source projects Nokcandu builds on, with links to support them.
- "Close Battle.net / Steam when the game quits" are now off by default.
