## New in 0.10.2

- **Named in Privacy & Security.** Each game's Wine now carries the game's name, so Input Monitoring and Microphone list "Counter-Strike 2", "Steam" and so on instead of a row of "wine" entries. Old "wine" entries can be removed with the − button; macOS asks again under the game's name if needed.
- **Steam games start reliably.** The shared Steam helper is updated even while Steam is running, so Play never goes through an outdated helper.
- **Right graphics mode for more Steam games.** Nokcandu also notices DirectX libraries a game loads while it runs (not only the ones it lists up front). Games like Chrono Trigger now start in Newer 3D games instead of a black screen in Older 3D.
- Shared Wine media libraries load correctly, and a game that was running when you changed its settings is reopened afterward.
