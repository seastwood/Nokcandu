## New in 0.10.2

- **Named in Privacy & Security.** Each game's Wine now carries the game's name, so Input Monitoring and Microphone list "Counter-Strike 2", "Steam" and so on instead of a row of "wine" entries. Old "wine" entries can be removed with the − button; macOS asks again under the game's name if needed.
- **Steam games start reliably.** The shared Steam helper is updated even while Steam is running, so Play never goes through an outdated helper.
- **Better graphics guesses for Steam games.** Nokcandu also notices DirectX libraries a game loads while it runs (not only the ones it lists up front), and re-checks a Steam game added before its download finished.
- **Game videos play.** Wine's video playback (GStreamer) now finds its libraries, so games like Chrono Trigger play their movies instead of failing. A game that was running when you changed its settings is reopened afterward.
