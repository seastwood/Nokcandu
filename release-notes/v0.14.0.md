# Nokcandu 0.14.0

## Controller profiles
- **Layers have colours.** Each layer has its own colour on its tab and across the controller picture, so you always know which layer you're editing. Pick a colour with the swatch next to the tabs; layers you haven't coloured get a distinct one automatically. On DualSense and DualShock 4 it is also the controller's light for that layer.
- **See what a layer changes at a glance.** A dot marks every button, stick or trackpad the layer you're editing sets differently, and a button that switches layers shows the colour of the layer it switches to.
- **Assign by pressing.** Turn on the switch above the controller picture, press a button on the controller (or push a stick one way), then press the key or mouse button it should be. With the switch off, pressing buttons only tests them.
- **Copy between layers.** Duplicate any layer as a starting point from the layer menu, or use "Copy from" on a button, stick, gyro or trackpad to bring its settings over from another layer.
- **Record a stick's keys.** A stick set to keys has a Record button for each direction.
- **Editing a layer stays in that layer.** Changing a stick, gyro or trackpad setting while a layer is selected now gives that layer its own copy instead of changing the base layer, and every other layer with it. Trigger pull and the touchpad, which apply to the whole profile, now say so.
- **No more buzz when switching windows.** With a layer on, every window switch used to rumble the controller; it no longer does. A layer you've toggled on also stays on through a brief controller dropout or reconnect instead of falling back to Base.
- **Controller arrow keys work with Mac shortcuts.** A button set to Control plus a stick set to the arrow keys now opens Mission Control and switches Spaces, like the keyboard does.

## Streams
- **Send Mac shortcuts to the host** (Keyboard and Mouse, on by default with "⌘ is the Windows key"): while the stream is in front, ⌘Tab, ⌘Space, ⌃←/⌃→, Mission Control and the other Mac shortcuts go to the host instead of the Mac. They come back as soon as you switch away or the stream ends. ⌃⌥⇧ shortcuts stay with Nokcandu (⌃⌥⇧D hides the stream).
- Keys from a controller profile in a stream carry the modifiers held with them, so a mapped Ctrl plus a mapped arrow reaches the host as Ctrl+arrow.
