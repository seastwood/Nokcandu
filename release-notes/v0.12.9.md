# Nokcandu 0.12.9

## Overwatch 2

- **Overwatch Setup** on the game's page in Battle.net: shows whether the game uses Metal for DirectX 10–11 (DXMT) and the low-memory DXMT build, and **Use Recommended Setup** sets both in one click.
- **Low-memory DXMT (Overwatch build)** is a new compatibility component for any DXMT game. It uses the community DXMT 0.80 build that frees shader data after compiling, which keeps Overwatch 2 from running out of memory during long matches. The download is checked against a pinned SHA-256, applies only to the selected program, and has its own Undo.

## Memory

- **Nokcandu watches how much memory each game uses while it runs** (its physical footprint, as Activity Monitor shows it). At a Glance shows the last session's peak.
- When a game used most of the Mac's memory, its page says so and how much it grew. For DXMT games it offers **Use Low-memory DXMT** in one click; for others it suggests lower texture settings and closing other apps.

## Getting ready for Apple silicon Wine

Native ARM64 Wine engines (no Rosetta) are starting to appear. Nokcandu now understands them, so they can be offered as soon as a Sikarugir ARM build is published:

- Engines are recognised by their layout (`aarch64-unix`/`aarch64-windows`) instead of assuming Intel paths. Launchers, the audio buffer setting, Native IPX, raw mouse and the game's own Dock identity all find the right files in either layout.
- ARM engine releases (`…_arm64.tar.xz`) are listed as **Apple silicon, experimental** and are never chosen automatically by updates; Intel builds of the same version stay first.
- Before a Windows environment moves to an ARM engine, Nokcandu checks the downloaded engine for the x86 emulator it needs (FEX: ARM64EC for 64-bit games, WoW64 for 32-bit games) and explains why when it can't run them yet.
- The resizable game window says plainly that it isn't available on ARM engines yet, instead of failing.
- An ARM engine paired with Intel-only wrapper files is refused with a clear message rather than installed half-working.

## Fixes

- **Overwatch, Heroes of the Storm and Diablo III start from Nokcandu.** Their Battle.net entries used the wrong launch code, so Play opened Battle.net without starting the game (and Overwatch's page didn't show Overwatch Setup). Existing entries are repaired automatically.
- At a Glance loads its facts off the main thread without a Swift 6 warning.
