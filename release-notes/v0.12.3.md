# Nokcandu 0.12.3

## Games, sound and networking

- Improved graphics detection for games with launchers and delayed DirectX imports, including Rocket League. Unknown requirements no longer default to an older DirectX mode.
- Fixed microphone privacy and input routing across supported Wine game types. Turning Microphone off stops capture while keeping game sound working; turning it on permits voice input with macOS consent. The switch can work during play without restarting the game.
- Fixed closed-connection handling in the shared Wine helper that prevented BF2Hub account login and server browsing. Internet multiplayer joining and basic gameplay were verified.
- Added optional IPX support for legacy games, including native Ethernet IPX interoperability with original Windows installations. Native IPX requires local administrator approval for packet access; access lasts until the last native-IPX game closes. LAN peers and VMs must use compatible network bridging.
- Added optional Battlefield 1942 master-server compatibility, with the relevant choices retained in game profiles.

## Settings and recovery

- Game settings now save without forcing a restart. Changes that need a closed game wait for its next full Windows-environment start; live microphone controls continue to apply immediately.
- Choose verified Sikarugir Wine versions per environment, set a default for new installations, or choose during installation. Wine 10.0 r8 remains the original tested default. Existing games keep their selected engine, with rollback available after a switch.
- Recipe installations allow supported settings changes and relocation instead of locking users to recipe defaults.
- Added Nokcandu app-version rollback in Settings → Updates. Managed replacements save the current app first; saved copies work offline, and older published releases can be downloaded with checksum verification. Each recovery copy includes a separate recovery command for a Nokcandu version that will not open. Games, saves and user settings are preserved; older apps may not understand newer settings.
- Repair checks more shared launcher and helper components and safely restores missing, outdated or damaged owned files while preserving manual edits.

## Installation, storage and reliability

- Completed supported game-store installations are added to the game list automatically.
- Installation runs in its own window so the game library remains usable while another game installs.
- Improved installer destination handling to avoid an unnecessary copy when supported installers honor the selected destination.
- Fixed shared external-drive launcher access and made startup failures visible instead of silently doing nothing.
- Storage settings load sections on demand and reuse recent measurements. Game totals include separately stored content and show usage on each drive.
- Tracked installer-image drive mappings are cleaned up safely after unmounting, with Undo; explicit user mappings and game discs are preserved.
- Reduced UI stalls during game-status checks and improved helper-version reporting.

## Notes

- Some shared-environment changes wait until its store client and other Windows programs close. Saving a setting does not force them to quit.
- IPX transport and discovery depend on the LAN/VM configuration; the same IP subnet alone does not establish native IPX connectivity.
- Existing recognized generated launchers migrate safely. Manually edited launchers are preserved and may require launching through Nokcandu to apply saved pending settings.
- Recovery copies use disk space and are retained until the user removes them. Independent recovery remains available even after returning to an older release that predates this feature.
