# Nokcandu 0.12.13

## Controller profiles

- **A short note shows when a layer or the gyro switches.** It shows the layer's name (or Base layer), Gyro on or Gyro off, and when a profile starts or stops being used everywhere. It appears at the bottom of the screen, over full-screen games, fades after a moment, and never takes clicks. Turn it off in Settings → "Show a note when a layer or the gyro switches".
- **The Profiles tab's New buttons line up** — both are menus now.
- **A new keyboard layout can start as a copy** of one you already have.
