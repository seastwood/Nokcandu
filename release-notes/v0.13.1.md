# Nokcandu 0.13.1

## Getting started
- **The welcome window asks what you came for:** remap a controller, stream games from your PC, or play Windows games. Only Windows games need Rosetta and the Wine engine, so if you only remap or stream, the setup checklist no longer appears on every launch. Help → Getting Started… reopens it.

## Controller profiles
- **Controller Settings have their own page in the Controls tab:** gyro calibration and its notes, pointer capture, headphone motion, connected controllers and diagnostics. Settings → General links to it.
- **One switch for automatic gyro calibration** turns it off for every profile, leaving only the calibrate shortcut or button.

## Streams
- **Quitting Nokcandu ends a running stream properly.** Keys and controllers are let go on the host and the connection is closed before Nokcandu exits, whether you quit, log out, shut down the Mac or install an update. Before, the stream simply stopped, which could leave a key held on the host. A Force Quit still can't be covered.
- **End Stream** removes the controllers from the host before closing the connection.
- The host and stream profile pages keep their scroll bar at the window's edge. The green on-air microphone icon is gone; macOS shows its own indicator.
- **Share the clipboard** and the **VBAN microphone** now say what they send: with clipboard sharing on, whatever you copy on the Mac goes to the host when you return to the stream, and VBAN is not encrypted, so use it on a network you trust.

## Security
- **Updates must come from Nokcandu's signer.** An update is installed only if it is signed with the same certificate as the Nokcandu you're running, on top of the existing checksum check. From this version on, an update that fails the check is refused with an explanation.
- **Games' input sockets are private.** The sockets Nokcandu uses to send controller mouse movement and clicks to Windows games moved into a folder only your account can open. Before, another account on the same Mac could have interfered with them.
- **No prebuilt Windows program in the source.** The small stand-in for games' Bonjour service is now compiled from its source when Nokcandu is built.
