# Nokcandu 0.15.2

## Streams: less delay from things drawn over the picture

- **Statistics and graphs are drawn into the stream's picture** with the Metal renderer, the same way the controller overlay is. A full-screen stream stays a single layer, so macOS shows it directly and nothing on top adds delay. With the display layer (AVSampleBufferDisplayLayer) they're still shown over the picture.
- **The controller overlay over a full-screen stream** is drawn into the stream's frames instead of a window above it (it added about 60 ms before). It keeps its colours, and the 3D drawing is only redrawn when something changed: a controller held still costs one small copy per frame.
- **V-sync on** (Metal): a frame that arrives a little late still makes the next refresh, and V-sync on asks for the screen's top refresh rate.
- **Hold notifications while playing or streaming** (Settings → Library, on by default): while a Nokcandu game or a stream is in front, Nokcandu's notifications wait until you leave it, and its notes when a controller layer or the gyro switches aren't shown.
- **Turn on Do Not Disturb while playing or streaming** (Settings → Library) silences other apps' notifications too. macOS only lets Shortcuts turn a Focus on, so Nokcandu makes two shortcuts ("Nokcandu Playing" and "Nokcandu Stopped Playing") and hands them to Shortcuts, which asks you to add each one. Nokcandu runs them when a game or stream comes to the front and when it leaves. If a shortcut fails, Settings says why. The Streams pages suggest it until it's set up.

## Controller overlay

- **Movement follows the controller properly**: the way you usually hold it is drawn level, and spinning it, tilting it side to side and tipping the front show as exactly those movements, however steeply you hold it (a held controller is often tipped up 50–60°). It settles back to level and facing the front a moment after you stop moving it; Recentre or holding Back and Start for a second does it at once.
- **Steam Controller and Switch Pro / PlayStation motion fixed**: turning read as tilting. Motion is read in SDL's axes for Steam Controllers (both models) and for controllers macOS knows, in the overlay and in controller profiles' gyro.
- **Hidden while no controller is connected** (a setting, on by default).
- **Seen from**: a new slider sets how high above the controller it's viewed from.

## Controller profiles

- **New gyro output: Steering wheel (left stick)**. Turn the controller like a wheel to steer: level is straight ahead, the right side down steers right. It works however you hold it (flat, tipped up towards you, or upright like a wheel): the gyro makes it quick and the controller's sense of gravity keeps it from drifting. **Full lock at** sets how far you turn for full steering (default 45°), and **Straight within** how much near level still counts as straight (default 2°). The left stick's own movement still adds to it.

## Game page

- **One Graphics setting** on the Display tab; **History & Restore** on Overview; one **Launch** section; **Performance & Sound**; fewer banners at the top (helper, status and store-update notices are with the other attention items).

## Apple silicon engines (preview)

- **Native Apple silicon Wine engines** (ARM64 Wine with FEX), from any source: Settings → Updates → Apple silicon engines installs MetalSharp Wine, or any GitHub repository you add with a file pattern, or an engine from a file. Each game's Wine version menu lists them with "(preview)", and switching uses the usual trial and Roll Back. These engines are kept exactly as built (macOS ties them to their own signature), and games link to them.
- **Add Engine From File** takes any Wine engine for macOS, Intel or Apple silicon. The Wine section shows each step of an engine switch, and a switch to another project's engine can't stop on Wine's Mono/Gecko download offer.
- **Running games on Apple silicon engines** (like MetalSharp) now show as running, so Steam on such an engine is detected again.
- **Resizable window (preview)**: Nokcandu's Mac driver (winenokmac) is installed on Apple silicon engines too. Games aren't confirmed to show their picture in the window yet; the setting says so.
- Test runs clean up after themselves (stopped runs could leave gigabytes in the temporary folder).

## Lighter while idle

- **Less CPU while Nokcandu is open**: checking which games are running now looks only at Windows programs instead of searching every process on the Mac once per game, Steam games likewise, and the resizable window's registry check is read once per change. The controller overlay works out each controller's details when it connects instead of 60 times a second.
