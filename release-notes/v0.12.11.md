# Nokcandu 0.12.11

## Easier to use

- **Drop to add.** Drop a setup program, disc images, a game folder or a folder of games on the library window.
- **Add a Folder of Games** (File menu, or Add a Game → Existing game folder). Nokcandu looks up to three folders down, picks each game's program (skipping setup programs, uninstallers, servers and tools), and lists them with a tick box, the name and the program to check. Ticked games are added where they are, one after another; folders that look like downloads or tools start unticked, and games already in your library are left out.
- **Won't start?** On a game's page, this checks the usual causes in order (drive connected, already running, a store app that stalled, a recent crash, missing files, permissions), repairs what it can and says what it found.
- **Recent changes.** The Overview tab lists what changed for the game — fixes, settings, keys, controllers — with Undo where possible.
- **Find a setting.** Type in the search field on a game's page (“mouse”, “fps”, “controller”…) to jump to the setting.
- **Simple and Advanced.** Simple shows the everyday settings, with the graphics choice on Overview; Advanced shows everything.
- **Change Several Games** (Game menu): pick games with tick boxes and set keys, controllers or graphics for all of them, or add them to Favorites.
- **Menu bar menu** (Settings → General): your recent games, Add a Game and the library, with Nokcandu staying open after its window closes.
- **The sidebar's buttons all fit when it's narrow.** Show and Sort share one button.

## Keyboard

- **fn (Globe) remapping works on Mac keyboards.** Nokcandu was using another form of the fn key than Mac keyboards send, so fn kept its own job (the emoji picker, say) and a key changed *to* fn stopped working in the game. Existing layouts are fixed when the game next starts.
- **Games inside Steam, Battle.net and other launchers can have keys of their own.** Each starts on "Same as Steam" (or Battle.net…); choose a layout, the default, normal keys or keys just for that game, and only that game's programs use them. It takes effect the next time the game starts.

## Adding games

- **Existing game folder: use it where it is, or copy it where you choose.** After choosing the folder, pick "Use it where it is" (nothing is copied; the game runs from that folder and it's kept if you remove the game) or "Copy it" to inside the game's app, any game folder, or any other folder. At a Glance says when a game uses your folder where it is.
- **Finding your games again.** Every game app is self-contained, so after reinstalling Nokcandu, on a new Mac, or with a drive of games copied from elsewhere, Nokcandu finds folders of its games on connected drives and offers to add them — nothing is copied. Settings → Storage → Drives & folders → **Find Games in a Folder…** looks through any folder or drive.
- **Your folder stays as it was.** A game using your folder where it is has "Keep my folder unchanged" on (Storage tab): fixes that would put files there are refused with an explanation, and after each session Nokcandu tells you if the game itself changed, added or removed files there — with That's Fine, Show Folder and Stop Watching — so you can switch to a copy before anything you care about changes.

## Performance

- **Games get the fastest cores.** A game's process asks macOS for top priority for its threads (Rosetta-translated games sometimes landed on the slower cores and stuttered).
- **Store apps step back while you play.** While a game is in front, Steam, Battle.net, the EA app and Ubisoft Connect run as background work (downloads and sign-in keep going) until you switch to them. Settings → General can turn this off.
- **Low Power Mode and heat.** While a game runs, Nokcandu says when Low Power Mode is on or the Mac is hot enough that macOS is slowing it down.
- **Resizable window, sharper and lighter at full size.** When the game runs at the display's own resolution (Retina included), each game pixel goes straight to a screen pixel with no filtering, and the window tells macOS nothing behind it needs drawing.
