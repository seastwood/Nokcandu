**Profiles carry everything again.** Game profiles now include the two settings added in 0.9.4:

- **Game resolution** — applied when your screen can run it (otherwise listed as skipped, so you can pick one in Display).
- **Audio buffer** — applied with the profile's other shared settings (when the game, or Steam, is closed), and undone by Undo.

Older Nokcandu versions ignore these two fields, so profiles shared from 0.9.5 still work there.
