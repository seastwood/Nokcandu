**Mouse settings tidy-up.**

- **Raw mouse capture** passes each mouse report straight to the game again (as in 0.9.6). Handing movement over once per frame is now an experimental switch in the Mouse section — off by default, applies while you play.
- Removed an internal timing measurement that added a little overhead to every Wine event.
- Tip: keep games like CS2 in Fullscreen Windowed and pick the resolution in Nokcandu (Game resolution); changing the display mode inside the game mid-match can make it quit.
