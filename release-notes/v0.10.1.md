## New in 0.10.1

- **Ubisoft Connect** sets up with a verified, undoable fix for its built-in browser, and the installer hands control back without waiting for launcher clients to close.
- **Changing a game's program no longer leaves you stuck.** If compatibility fixes are set up for the current program, Nokcandu now lists them, and with one confirmation takes a restore point, undoes them, switches the program and sets them up again for the new one. The message you'd see elsewhere now names the fixes involved.
- DLL fixes keep the graphics mode's own rules (for example DXMT or Apple Metal) instead of replacing them.
- **Steam games start reliably.** When Steam is already running with other settings, Nokcandu now asks in its own window whether to restart Steam or play without restarting (before, the question could open behind other windows, so Play looked like it did nothing).
- Steam games now show as Running in the library while they play.
- A Steam game added before its download finished gets the right graphics mode from its program the first time you press Play.
- Clicking games in the library always selects them (double-click still plays).
- Mac screen resolution help explains that some games only offer resolutions that fit the screen.
