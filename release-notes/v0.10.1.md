## New in 0.10.1

- **Ubisoft Connect** sets up with a verified, undoable fix for its built-in browser, and the installer hands control back without waiting for launcher clients to close.
- **Changing a game's program no longer leaves you stuck.** If compatibility fixes are set up for the current program, Nokcandu now lists them, and with one confirmation takes a restore point, undoes them, switches the program and sets them up again for the new one. The message you'd see elsewhere now names the fixes involved.
- DLL fixes keep the graphics mode's own rules (for example DXMT or Apple Metal) instead of replacing them.
