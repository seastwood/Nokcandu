# Nokcandu 0.12.6

## Space

- **Wine engine stored once per drive.** Apps on another APFS drive (for example a games volume) each carried a full copy of the Wine engine. Identical engine files on the same drive are now stored once, as they already are on the Mac. Moving a game to such a drive shares its engine automatically; for apps already there, **Storage → Free Up Space → Share** does it. Only byte-identical files are shared, so an engine adjusted for one game keeps its own version; game files, Windows setup and saves are never touched. On the reporting Mac this freed about 3.7 GB on a games volume holding five games.
- **Moves continue where they stopped.** If a move is interrupted (Nokcandu quit, the Mac slept, a drive came loose), the copy made so far is kept. Moving the game to the same place again continues it instead of starting over; files already copied are checked by size and date, and the finished copy is still compared file by file before anything is removed. The Move window says when an earlier move stopped, and **Free Up Space** lists unfinished copies to delete.

## Fixes

- Games on an APFS games volume now show up in Spotlight and Launchpad (indexing is turned on for games volumes), and a moved game no longer leaves its old location registered.
- Starting a game macOS is checking (the first time it opens after its files changed, for example after a move) is no longer reported as "didn't start" after 12 seconds; Nokcandu waits up to a minute and says what's happening.
- **Quit** no longer waits up to 25 seconds for a game that doesn't answer Windows' close request; programs get 10 seconds, then they're stopped.
- Game status no longer flashes "Status unavailable" while a game is quitting.

## Known issues

- The microphone-Off permission prompt and the Battlefield 2 fullscreen Spaces input issue described in 0.12.3/0.12.4 remain open.
- A game's microphone permission belongs to its location: after moving a game with the microphone On, macOS asks again the first time it uses the microphone.
