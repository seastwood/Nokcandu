**Game Profiles** — share and apply the settings that make a game work.

- New **Game Profiles** window: search everyone's shared profiles, see how well each game runs (Works great / Playable / Doesn't work), votes and comments, and apply one in a click. Profiles reported broken by many people are tucked away.
- Each game's page shows profiles shared for it, plus **Share This Setup…**, which opens a pre-filled GitHub submission. Submissions are checked automatically and appear within an hour — no approval needed.
- Profiles are settings only (graphics, launch options, extra settings, raw mouse, performance, needed fixes). They can't contain files, paths or scripts, so applying one is safe.
- **Try a profile on any game** — e.g. a similar game with no profile yet — and **Undo** puts the previous settings back.
- Website: https://seastwood.github.io/Nokcandu/ — "Open in Nokcandu" links straight to a profile.

If you're on 0.9.0, use **Updates…** to update in place.
