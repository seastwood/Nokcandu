**Game stores, games as real Mac apps, and Game Mode.**

### Games feel like Mac apps
- **Game Mode** — each game now runs as its own small Mac app, so macOS turns on Game Mode (top CPU/GPU priority, faster Bluetooth mice and headphones) when it's full screen.
- **Real names in the Dock** — "Counter-Strike 2", "Steam", "Worms Armageddon" instead of "wine", in the Dock, Cmd-Tab and Activity Monitor. Settings → Advanced can switch this off.
- **Rename games** and give them your own subtitle.

### Game stores
- **One Game Stores window** for Steam, GOG, Epic Games and Amazon: sign in, browse your library and install — with the Mac version when a game has one. EA app, Ubisoft Connect and the store launchers are optional extras for games that need them.
- **Add a Game** can also link a Mac game you already have (e.g. OpenMW), so everything lives in one place.

### Where games live
- **Install location per game** — on your Mac or an external drive (game files can live on ExFAT drives).
- **Move To…** for installed games, and a **"Drive not connected"** section when a game's drive is unplugged.
- **Sidebar**: Favorites, Games and Launchers, with sorting.

### Help for each game
- **Anti-cheat notes** from AreWeAntiCheatYet — a warning only for kernel-level anti-cheat, which Wine can't run.
- **Known fixes** from the umu/Proton community database, applied with winetricks, and the **best-rated community profile** suggested for new games.
- **Profiles**: read comments, see live votes, star favorites (kept as they were when starred, with the latest version alongside), and restore a setup saved with a note.

### Settings
- A **Settings window** (gear button) with General, Storage, Accounts, Updates and Advanced, including shader caches.

### Fixes
- **Mouse clicks no longer move the cursor** with Raw mouse on (a regression in development builds; 0.9.5 was fine).
- **FPS counter works with DXMT.**
- **CS2 keeps its video settings** when you switch between Apple Metal and DXMT (both now report the same graphics card).
- **CS2 starts again** when an optional log file was missing; fewer repeated macOS permission prompts (builds keep one signature).
- Older Zero Hour and Worms installs now load Nokcandu's helper library (names, Game Mode, raw mouse).
- Performance tips rewritten to be accurate (lower the resolution first; Low Power Mode off).
