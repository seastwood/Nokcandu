# Nokcandu 0.12.8

## Easier to use

- **Play shows what it's doing.** Under the Play button: getting the game ready, starting Windows, waiting for Steam or Battle.net (sign in if it asks), macOS checking the game before it opens, starting the game — until its window appears.
- **One place for notices.** Crash explanations, mods missing other mods, graphics problems, video playback crashes and anti-cheat warnings share one area at the top of the game's page: the most important one is shown, the rest are one click away.
- **At a Glance** on the Overview tab: graphics mode, engine, where the game is stored, raw mouse, when you last played and whether the last run crashed. Click a line to go to the tab where it's changed; Diagnostics, Show in Finder and Move are right there.
- **Plain explanations** next to technical settings: the Wine engine, the program Play starts, Rebuild Launcher and Fixes each have an (i) or a short note.
- **Quitting**: "Always Quit Without Asking" in the quit prompt (turn asking back on in Settings → General). Launchers with no game running in them quit without asking.
- **Recent activity**: the bell in the toolbar keeps the last 30 messages, so ones that faded can still be read; a red dot means something went wrong.
- **Search and filters** in the sidebar: search by name or subtitle, or show only running games, Windows or Mac games, Steam, Battle.net, or the games on one drive.
- **Welcome**: a new library shows the three ways to add a game (disc or installer, a store, a game you already have) and what macOS will ask for.
- **Game menu shortcuts**: ⌘↩ plays or quits the selected game, ⌘1–⌘6 switch its tabs, ⌘F searches.
- Restore Points, Notes and launcher-game settings use the same layout as the rest of the page. Raw mouse says when macOS hasn't allowed Input Monitoring and links to the setting.

## Known issues

- The microphone-Off permission prompt and the Battlefield 2 fullscreen Spaces input issue remain open.
