**Voice chat, smoother aiming and steadier fullscreen** — mostly tuned on Counter-Strike 2.

- **Microphones work.** Wine asked macOS for the *default output* audio unit even when recording, which current macOS refuses. Nokcandu fixes that in each app's copy of Wine's audio driver (original kept), so Steam voice and in-game chat hear you.
- **Audio buffer** (Performance): Normal 10 ms, Large 20 ms or Extra large 40 ms chunks. Large fixes crackle and static in games like CS2.
- **Game resolution** (new Display section): while the game runs, your Mac's screen switches to exactly the chosen pixels and your own desktop comes back when it quits. Use the game's *Fullscreen Windowed*: nothing switches while you play, so alt-tab and changing settings can't break the window.
- **Low-latency aiming** and a separate **Game frame cap** for CS2 and Valve's Source games (vsync off; CS2 reads the mouse as late as possible; recommended cap is twice your screen's refresh).
- **Raw mouse** reads the mouse hardware directly — any mouse, plugged in any time. Smooth movement uses finer steps.
- **Steam and Battle.net close after the game that opened them**, so the next game starts them with its own settings. If you opened them yourself they stay open. Toggles on their pages.
- **Steam restart check:** if you changed a game's graphics, performance or mouse settings since Steam started, starting the game asks to restart Steam first (or play anyway).
- Real game names in the Dock instead of "wine". Steam performance tips. Clearer app names when one is taken ("StarCraft (2)"), and leftovers from unfinished setups are reported instead of duplicated.
- Diagnostics and the engine self-test say when an engine update changes Wine's audio driver so the microphone fix can't apply.
