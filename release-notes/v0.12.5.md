# Nokcandu 0.12.5

## Faster and lighter

- Nokcandu now uses a fraction of the CPU it did while idle (measured on a MacBook Air: about 25–40% before, under 1% in the background and a few percent with its window in front). Game status is checked often only while Nokcandu is in front; starting and quitting games are noticed immediately.
- Switching between games no longer pauses the window: game pages, the Fixes list, Wine versions and pending changes are read in the background.
- Startup no longer keeps the Mac busy for several seconds; launcher registries and game folders are read only when they change.

## Space and storage

- **Move…** shows what a game is made of — the app (Wine engine, Windows setup, saves) and the game's own files — with sizes and where each is, and lets you choose a place for each: for example the app on an APFS drive and the game's files on an ExFAT drive. Copies are checked file by file before anything is removed, and show progress.
- Moved apps stay in your Applications folder (as a link to the drive). Games moved by earlier versions get their link back automatically.
- Launchers (Steam, Battle.net, EA app, Ubisoft Connect) can now move to another drive with all their games.
- **Storage → Drives → Create APFS Games Volume** on ExFAT drives: a growable APFS volume stored on the drive that holds whole games and launchers without ExFAT's wasted space, opened automatically whenever the drive is connected. Existing volumes can be used too, and **Eject** closes them before ejecting the drive.
- **Storage → Free Up Space** lists what can safely go: restore points of apps that moved or were removed, leftover app folders, the previous engine kept for roll back, downloaded installers, and games whose files waste space on ExFAT.
- Sizes now show what a game really adds: the Wine engine each app shares with others through APFS clones is listed separately instead of being counted again for every game.
- Automatic restore points: the newest 3 per app are kept, and older automatic ones are removed after 30 days. Restore points follow a move on the same drive; on a different drive a fresh one is taken.
- An engine tried for a week and played since is kept automatically, removing the old engine's copy (a restore point from before the change remains).
- Logs are kept for 30 days, at most 20 MB per game and 150 MB in total.

## Fixes

- Moving a game no longer makes Nokcandu treat it as an unfinished installation, and no longer leaves an empty app folder behind that kept reopening the installer. Existing records and leftover folders are repaired automatically.
- A launcher Nokcandu itself brought up to date is no longer reported as "edited outside Nokcandu".
- The "helper needs updating" note no longer appears briefly after Nokcandu starts.

## Game settings

- Each game's settings are organized into tabs: Overview, Display, Performance, Controls, Wine & Fixes and Storage. The last tab you used is remembered.

## Known issues

- The microphone-Off permission prompt and the Battlefield 2 fullscreen Spaces input issue described in 0.12.3/0.12.4 remain open.
- Apps moved to another APFS drive store their own copy of the Wine engine there (clones can't cross drives).
