# Nokcandu 0.12.14

## Controller profiles

### Gyro and layers
- **Layers can have their own stick and gyro settings** — a slower aim layer, a layer where a stick scrolls, a different gyro sensitivity. Turn on "Own stick settings" or "Own gyro settings" with that layer selected.
- **Smart smoothing for the gyro** (a One Euro filter): steady when you aim slowly, no lag when you flick. In the gyro's Filter section.
- **Calibrate the gyro any time:** give a button, a combination or a sequence "Calibrate the gyro", set a keyboard shortcut in Settings, or press Calibrate in the editor's test. It also calibrates by itself when you put the controller down. The on-screen note shows a progress bar either way.
- **Tilt as buttons:** tilting the controller left, right, forward or back works like four more buttons.
- **Feedback:** a short rumble when the layer changes, a light colour per layer on DualSense and DualShock 4, and a "Rumble" action for any button. Test the rumble in the profile's Feedback section.

### New ways to use the controller
- **Touchpad** (DualSense, DualShock 4): a mouse with two-finger scrolling, scrolling, or four zones to touch and click.
- **Macros:** several keys with pauses between them, holding keys, and typed text, from one press. Record one by typing.
- **Sequences:** buttons pressed one after another (up, up, down…) do something extra.
- **Radial menus:** hold a button, point a stick at one of up to eight choices, let go.
- **On-screen keyboard:** type with the controller.
- **Sticks can scroll**, and each stick direction can be set on its own (keys, clicks, buttons, tap and hold, layers). The picture shows what each stick does.

### Devices
- **Combine devices in one profile:** add up to four joysticks, throttles, pedals, wheels, button boxes or other controllers with **Add Device**. Each button, hat and axis can be set like a controller button, and an axis can move a stick, a trigger or the mouse — two pedals as one rudder, for example. Press something on the device to select it.
- **A second controller can join the main one**, so two controllers (or two halves held in each hand) act as one.
- In Windows games, anything on a device you leave alone still reaches the game from the device itself.

### Profiles
- **Share a profile:** Share → Copy to Clipboard or Save as File; the other person chooses New Controller Profile → Paste Shared Profile or Import from File.
- **Undo and redo** in the profile editor (⌘Z, ⇧⌘Z).
- **A controller can pick the Mac's profile:** in Settings, choose a profile to use while a particular controller is connected.
