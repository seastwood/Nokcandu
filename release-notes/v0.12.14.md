# Nokcandu 0.12.14

## Controller profiles

- **Combine devices in one profile.** Add up to four joysticks, throttles, pedals, wheels, button boxes or other controllers next to your controller with **Add Device** in the profile editor. Each button, hat direction and axis can be set like a controller button, and an axis can move one of the controller's sticks or triggers, or the mouse. Several axes can drive the same stick — two pedals as one rudder, for example. Press a button or move an axis on the device to select it.
- **A second controller can join the main one:** what you don't set on it acts as the main controller's own buttons and sticks, and Windows games see one controller — for two halves held in each hand, or two controllers for one player.
- In Windows games, anything on a device you leave alone still reaches the game from the device itself, as usual; what you set takes its place. Buttons and axes are numbered the same way Wine numbers them, so a setting means the same control in Windows games and on the Mac.
- **Each stick direction on its own:** set a stick to *Four directions* and give up, down, left and right anything a button can do — keys, clicks, controller buttons, tap and hold, layers. Diagonals press both. Switching from *Keys* keeps the keys it had.
- **The controller picture shows what each stick does** (Mouse, Flick, WASD, the other stick…) and what its click does.
