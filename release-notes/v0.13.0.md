# Nokcandu 0.13.0

Nokcandu is now licensed under the GNU GPL, version 3 (releases up to 0.12.18 stay MIT). The new Streams tab is built on GPL-3.0 code from VoidLink and moonlight-common-c.

## Streams (new)
- **Play games running on another computer.** The Streams tab is a client for Sunshine, Apollo and NVIDIA GameStream hosts: find hosts on your network or add one by address, pair with a PIN, and start any of the host's apps.
- **Stream profiles** per host: the app to start, resolution, frame rate, bitrate, codec, sound, the display to use, the keyboard layout, and which controller the host sees.
- **Controllers in a stream:** pass your controller through as it is, or use a Nokcandu controller profile, whose mapped controller, keys and mouse go to the stream instead of the Mac.
- **End Stream** and **End and Quit** in the Stream menu, with shortcuts; settings can be changed while a stream runs; full screen uses Game Mode.
- **VBAN microphone:** send your Mac's microphone to the host over VBAN, with gain, gate, compressor, EQ, mute, push-to-talk and a level meter.
- **Clipboard sync with Apollo hosts** (off by default). New and not yet tried against a real host.

## Controller profiles
- **Emulated controller.** A profile can present itself as an Xbox controller, a DualShock 4 or a Switch Pro Controller, to Windows games and to streams. Confirmed to appear correctly to Windows; not yet tried in many games.
- **A profile that reads the controller itself is the only version of that controller a Windows game sees.** Before, the game also got the raw controller mapped a second time and differently (reported in Trackmania).
- **"Use a Profile Everywhere" now reaches Windows games' controller,** so gyro-as-stick and remapped buttons apply there too.
- **Game rumble on controllers that couldn't rumble.** A game's vibration now plays on the original Steam Controller's trackpads, or through macOS haptics for other controllers, with a per-profile strength (60 % by default).
- **Controls tab:** a "This game gets" summary, clearer names for controller sources and routes, and the controller picture shows combined outputs and trackpad zone names.

### Gyro
- **Drift is corrected quickly and quietly.** Whenever the controller hasn't moved for about five seconds, in your hands or put down (about three seconds on a table), its drift is measured again. Nothing shows on screen unless a clear drift was corrected. Calibrating with a button or shortcut works as before.
- **A good calibration is no longer replaced by a worse one.** A calm hand could pass for "put down", and the quick measurement taken then was off. It also no longer gets lost when the app in front uses another profile, a profile is edited, or a stream starts.

### Original Steam Controller trackpads
- **No more jiggle, resting or moving.** The pointer holds still under a resting thumb, and the pad's sensor noise is filtered while the thumb moves, in proportion to how noisy the pad is. Slow movement is steady; swipes stay immediate.
- **Smooth movement on the Mac desktop with gyro aiming on.** The gyro's small movements were overwriting the trackpad's, so the pointer stuttered (streams were not affected).

## Fixes
- **A layer you switched on stays on when you switch windows,** and so does the gyro's on/off switch. Keys and buttons held into the old app are still let go.
- **Controller profiles can no longer disappear.** One unreadable value (a trackpad tap set to Tap/Hold) made the whole library show as empty. Profiles are now read leniently, the original file is kept as a backup, and that value can no longer be saved.
- **Trackmania's "free up 5 GB" memory warning.** Windows games now see the memory macOS can actually give them. New and not yet confirmed in the game.
