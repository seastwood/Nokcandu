## New in 0.10.0

- **Restore points.** Before fixes, Apply Recommended, Proton community fixes, the cinematic fix and engine changes, Nokcandu takes an instant snapshot of the game's whole Windows setup (an APFS clone — it uses almost no space until things change). The game page lists them; Restore puts the game back exactly as it was (and keeps the current state as its own restore point, so you can switch back). You can also take one by hand.
- **Stay on this engine.** In Updates, pin a game that plays well to its current Wine engine while the others try newer ones.
- **Report a Problem** (game page, and Help menu): writes a report with your Nokcandu and macOS versions, Mac model, the game's setup and diagnostics — with your name, user name, computer name, email addresses and Steam IDs taken out — shows you exactly what will be shared, and opens a prefilled GitHub issue.
- **Game updates for GOG and Epic.** Nokcandu checks every few hours (or File → Check for Game Updates); games with a newer version show "Update available" with an Update button and progress.
- **Epic cloud saves.** For games installed from Epic, a newer cloud save is downloaded before the game starts and your save is uploaded after it quits (Settings → Advanced to turn off).
- **DLC.** When installing from GOG or Epic, the DLC you own is listed with an "Include" checkbox.
- **Bring games over from other Mac Wine apps.** Add Game lists their bottles and games; Bring Over copies the game (instantly on the same drive) along with its saves and settings.
- Steam downloads show a percentage. Settings → Advanced lists connected game controllers.
- Releases can now be notarized once an Apple Developer ID is added to the project.

Note: Apple keeps full Rosetta 2 through macOS 27; after that it plans to keep only a subset aimed at older games. Nokcandu depends on it and will follow what Apple ships.
