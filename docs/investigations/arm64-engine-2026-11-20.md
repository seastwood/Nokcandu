# ARM64 engine: state of things and plan (2026-11-20)

Follows [overwatch-and-arm64-wine-2026-11-05.md](overwatch-and-arm64-wine-2026-11-05.md), which made Nokcandu
recognise ARM engines (`EngineLayout`, `EngineVersion.arch`, `WineSelection.incompatibility`).

## Why now

- Rosetta: macOS 27 removes it on install (reinstallable); macOS 28 (autumn 2027) keeps it only for some older,
  unmaintained games, and whether Wine counts is unknown. An ARM engine has to be solid by then.
- macOS: CodeWeavers (Brendan Shanks, wine-devel, 2026-08-07): all the pieces for native ARM64 Wine are in macOS
  26.5 and later (an x18 custom ABI for Windows code, 4K pages for signed apps with the cross-architecture
  entitlement). CrossOver Preview ships ARM64 Wine with FEX (ARM64EC for x86_64, WoW64 for i386).
- Wine upstream: ARM64EC complete since 10.0; 11.20 relay debugging for ARM64EC; 11.22 AVX in the x86 emulation
  path. The macOS-ARM64 patches themselves were not merged as of 11.18 (no later news found).
- Graphics: DXMT builds ARM64EC/ARM64X in CI (Aug–Sep 2026). D3DMetal for ARM64EC not confirmed: D3D12 games may
  stay on Rosetta for a while.

## Plan

1. **Prototype** (this session): run x86_64 and i386 test programs and one or two games on a prebuilt engine;
   compare start-up, frame rate and input against the Rosetta engine.
2. **Nokcandu's own pieces for ARM**:
   - `nokcandu-rawmouse.dylib` and the launcher are already universal (arm64 + x86_64).
   - The window driver (`Engine/winemac`) and native IPX's wpcap are x86_64 only: need `aarch64-unix` builds of
     the unix side and ARM64X builds of the Windows side, against the same Wine tree as the engine (the driver
     must match the engine's wineserver protocol, as `WindowedPresentation.serverRequestsMatch` checks).
3. **Our own engine build** (CI): one patched Wine tree (the macOS-ARM64 patches + Nokcandu's driver patches),
   FEX for ARM64EC and WoW64, DXMT ARM64X; signed with the cross-architecture entitlement so i386 games work.
   Prebuilt third-party engines are fine for testing but tie the driver patches to someone else's tree.
4. **In the app**: ARM engines offered per game as a preview, Rosetta stays the default; the Wine picker shows
   which games an ARM engine can't run (`WineSelection.incompatibility`).
